# Voice Inbox

A one-button voice notes web app. Hold the button, speak, let go.

- Notes are saved on the phone first, then sent to the owner's own storage.
- Speech-to-text runs on the phone (Moonshine, via transformers.js). Audio is not sent anywhere for transcription.
- Works offline once installed. Setup happens through a private link; this repo holds no keys or addresses.

Third-party code: `vendor/qrcode.js` (QR Code Generator, Kazuhiko Arase, MIT licence).
